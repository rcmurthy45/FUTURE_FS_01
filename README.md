## 📖 About

A modern, fully responsive personal portfolio website built for **Surla Ram Chandra Murthy** — a B.Tech student specializing in Artificial Intelligence & Data Science at Vignan Institute of Information Technology (VIIT), Visakhapatnam. The portfolio showcases projects, skills, education, certifications, and contact information with smooth animations and a dark futuristic aesthetic.

---

## ✨ Features

- **Animated Hero Section** — Typewriter effect cycling through roles (AI & DS Student, Full Stack Developer, Future Data Engineer, etc.) with an interactive particle canvas background
- **About Section** — Trait cards highlighting key strengths with animated entrance effects and key stats
- **Education Timeline** — Academic journey from school to B.Tech
- **Skills Section** — Tabbed interface (Frontend / Backend / AI & Data Science / Tools) with icon cards powered by devicon SVGs
- **Projects Showcase** — Featured AI project cards with live demo and GitHub links
- **Certificates** — Industry certifications and academic achievements
- **Contact Form** — Integrated with Supabase for message handling
- **Resume Download** — One-click `.docx` resume download
- **Smooth Animations** — Powered by Framer Motion throughout
- **Fully Responsive** — Optimized for mobile, tablet, and desktop

## 💻 Getting Started

### Prerequisites

- Node.js v18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/rcmurthy45/FUTURE_FS_01.git
cd FUTURE_FS_01-main

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build locally |
| `npm run lint` | Run ESLint |
| `npm run typecheck` | Run TypeScript type checking |

## 🌐 Deployment

This project is deployed on **Vercel**. To deploy your own instance:

1. Push the repository to GitHub
2. Import the project on [vercel.com](https://vercel.com)
3. Vercel auto-detects Vite — no additional configuration needed
4. Add your Supabase environment variables in Vercel's project settings
